# Бот расписания ВГПУ

Telegram-бот для студентов: берёт расписание с сайта [rsp-vspu.online](https://rsp-vspu.online/)
и показывает пары своей группы. Ещё в нём можно посмотреть расписание любого преподавателя.
Интерфейс на русском, английском и португальском — для иностранных студентов.

## Что умеет

Расписание группы открывается кнопками под полем ввода: **🕐 Сейчас**, **📅 Сегодня**,
**➡️ Завтра**, **🗓 Неделя**, **⏭ Через неделю**.
Бот присылает его таблицей: № | Время | Дисциплина | Преподаватель | Ауд.
Для таблиц используются rich-сообщения Telegram (Bot API 10.2+, `sendRichMessage`).
Если Telegram не примет rich-сообщение, бот пришлёт то же расписание обычным текстом.

- «Сейчас» — какая пара идёт и сколько до её конца; в перерыв — какая следующая и через сколько;
  если пары на сегодня кончились — ближайшая пара в следующие дни (ищет на две недели вперёд).
- «Неделя» — с понедельника по воскресенье текущей недели, а в воскресенье — следующей.
- «Через неделю» — неделя после неё: расписание чередуется по неделям.
- Пустое воскресенье не показывается.

Если сайт расписания недоступен, бот показывает сохранённую копию с пометкой
«⚠️ Сайт недоступен, копия от …» (подробнее — в разделе «Как это работает»).

| Команда | Что делает | В меню |
|---|---|---|
| `/start` | выбор языка, приветствие и выбор своей группы | |
| `/teacher` | посмотреть расписание преподавателя, не меняя группу | ✓ |
| `/subject` | найти преподавателя по предмету: `/subject философия` или `/subject`, и бот спросит | ✓ |
| `/group` | сменить группу | ✓ |
| `/language` | сменить язык | ✓ |
| `/now`, `/today`, `/tomorrow`, `/week`, `/nextweek` | то же, что кнопки | |
| `/help` | список команд | |
| `/reset` | удалить данные о пользователе и начать регистрацию заново, с выбора языка (скрытая: бот её нигде не упоминает) | |

Группу можно ввести не целиком: `ан 251` найдёт `ИЯ-АН_Оb251` (регистр, дефисы и
русские/латинские буквы не важны). Ещё её можно выбрать кнопками: факультет → направление → группа.
Своя группа запоминается в SQLite, дальше хватает кнопок.

Иностранным студентам трудно набирать кириллицу, поэтому группу и преподавателя можно искать
латиницей: `AN 251` найдёт `ИЯ-АН_Оb251`, `Anisimova` — `Анисимова О.Н.`
(транслитерация как в загранпаспорте; «х» можно писать и `kh`, и `h`).

### Расписание преподавателя или другой группы

- `/teacher` → фамилия или первая буква → карточка с расписанием преподавателя
  (колонка «Группы» вместо «Преподаватель»);
- или просто написать в чат фамилию преподавателя или название другой группы.

Своя группа при этом не меняется. Под карточкой кнопки **Сейчас · Сегодня · Завтра · Неделя ·
Через неделю** переключают период в том же сообщении: «Сейчас» подскажет, где преподаватель
прямо сейчас или где у него ближайшая пара. В карточке чужой группы есть ещё кнопка
**📌 Сделать моей группой**.

### Поиск преподавателя по предмету

`/subject философия` (или просто `/subject` — бот спросит предмет) показывает таблицу
«Дисциплина | Преподаватель | Группы» и кнопки с преподавателями — они открывают их расписание.
Кто ведёт предмет в твоей группе, отмечен ⭐ и стоит первым. Предмет можно писать частично
и латиницей (`filosofiya`). Если подходит больше 10 предметов, показываются первые 10 и «и ещё N».

На сайте нет списка «кто что ведёт», поэтому бот собирает его сам — из расписаний всех групп
(в каждой ячейке есть и предмет, и преподаватель):

- раз в сутки (и через 2 минуты после первого запуска) бот обходит все ~300 групп, по одной
  в 1,5 секунды — около 8 минут; после перезапуска не пересобирает, если индекс свежий;
- индекс лежит в базе, поэтому `/subject` работает, даже когда сайт недоступен;
- если сайт подвёл посреди обхода (5 ошибок подряд или не загрузилась четверть групп),
  старый индекс остаётся — полупустой его не заменит; следующая попытка через час;
- сайт отдаёт расписание на месяц-два вперёд, поэтому найдутся только предметы,
  по которым в это время есть пары.

### Языки

При `/start` бот спрашивает язык — сразу на всех трёх, — потом группу. Сменить язык — `/language`.
На выбранном языке весь интерфейс: кнопки, подсказки, даты, заголовки таблицы, типы занятий
(«лекция» → *lecture* / *aula teórica*), подгруппы и меню команд. Названия предметов, фамилии
и аудитории остаются как на сайте, по-русски, — об этом сказано в `/help` на английском и португальском.
Админские `/stats` и `/broadcast` — только по-русски.

Тексты лежат в отдельных файлах, по одному на язык:

| Файл | Язык |
|---|---|
| `locales/ru.toml` | русский — основной: если в другом файле нет ключа, берётся текст отсюда |
| `locales/en.toml` | английский |
| `locales/pt.toml` | португальский |

Править их можно без знания Python: это [TOML](https://toml.io/ru/) — `ключ = "текст"`,
многострочный текст в тройных кавычках, комментарии через `#`. Подстановки в фигурных скобках
(`{group}`, `{time}` …) бот заполняет сам — их нельзя переводить или удалять.
Тест `test_locales_complete` проверяет, что во всех файлах одинаковые ключи и подстановки.

Добавить язык: скопировать `ru.toml` в `<код>.toml`, перевести и дописать код в `LANGS` в `i18n.py`.

Кто пользовался ботом до появления языков, остаётся на русском — даже если Telegram у него
на английском. Новым пользователям до выбора язык подбирается по настройкам Telegram.

### Для админа

Админы задаются переменной `ADMIN_IDS` (Telegram ID через запятую). Им в меню добавляются
две команды, остальные пользователи их не видят, а бот на них молчит.

| Команда | Что делает |
|---|---|
| `/stats` | пользователи, заблокировавшие бота, новые и активные за сутки/неделю/месяц, топ групп и факультеты |
| `/broadcast текст` | рассылка всем, кто не заблокировал бота |

**Рассылка.** Текст пишется после команды, можно в несколько строк. Поддерживается Markdown:
`**жирный**`, `*курсив*`, `~~зачёркнутый~~`, `[ссылка](https://…)`, `# заголовок`,
списки, цитаты `> …`, таблицы. Форматирование, сделанное кнопками Telegram, тоже сохраняется.
Сообщение уходит rich-сообщением, поэтому экранировать символы, как в MarkdownV2, не нужно.

1. Бот присылает превью ровно в том виде, в каком его получат пользователи, и спрашивает
   «✅ Отправить (N)» / «✖️ Отмена».
2. После подтверждения рассылка идёт в фоне, примерно 20 сообщений в секунду (лимит Telegram — около 30).
   Каждые 50 получателей бот обновляет сообщение с прогрессом.
3. В конце приходит отчёт: доставлено, заблокировали бота, ошибки.
   Заблокировавших бот помечает и больше не включает в рассылки, пока они снова ему не напишут.

**Как узнать свой ID:** отправьте боту `/stats`. Бот промолчит, а в лог запишет строку
`Админская команда от не-админа: user_id=…`. На сервере её можно найти так:
`journalctl -u vspu-schedule-bot | grep не-админа`.

## Какие данные хранятся

База SQLite (на сервере — `/var/lib/vspu-schedule-bot/bot.db`):

| Таблица | Поля |
|---|---|
| `users` | Telegram ID, выбранная группа |
| `activity` | Telegram ID, @username, имя, фамилия (как в профиле Telegram при последнем обращении), выбранный язык, время первого и последнего обращения, заблокировал ли бота |
| `schedules` | копии расписаний групп, которые выбраны хотя бы у одного пользователя, и время загрузки с сайта; данных о пользователях здесь нет |
| `subject_index`, `meta` | индекс для `/subject`: предмет, преподаватель, группа — и время сборки; данных о пользователях здесь нет |

Имя, фамилия и username обновляются при каждом сообщении или нажатии кнопки.
Текст сообщений, поисковые запросы и просмотренные расписания не сохраняются.
`/reset` удаляет обе строки пользователя.

## Как это работает

Сайт сделан на Django. На главной странице два списка (`<select>`): группы и преподаватели.
Расписание приходит в ответ на `POST /group` или `POST /teacher` с CSRF-токеном
со страницы и cookie `csrftoken`. Ответ — HTML-таблица с понедельника текущей недели
на месяц-два вперёд (с октября 2026 — около двух месяцев):

- строка с `rowspan` начинает новый день: дата и день недели. С октября 2026 под датой
  ещё и тип недели — `12-10-2026<br><br/>числитель` / `знаменатель`; бот показывает его
  в заголовках дня и недели;
- строки `class="gran"` — пары: время и по ячейке на каждую подгруппу;
  пара у всей группы — одна ячейка с `colspan` на все подгруппы;
- текст ячейки у группы: `Предмет(тип)-Преподаватель - аудитория`,
  у преподавателя: `Предмет(тип)-аудитория[группа],[группа]`.

Ответы сайта кэшируются в памяти: расписание на 15 минут, списки групп и преподавателей на 6 часов.

Если в таблице не нашлось ни одного дня, это считается ошибкой сайта, а не пустым расписанием:
значит, поменялась вёрстка (так было в октябре 2026, когда под датой появился тип недели).
Тогда бот показывает сохранённую копию, а копии и индекс предметов не затираются пустыми.
В логе при этом будет «не нашлось ни одного дня — изменилась вёрстка сайта?» — повод поправить
парсер в `vspu.py`.

### Если сайт недоступен

Для групп, которые выбраны хотя бы у одного пользователя, бот хранит копию расписания
в таблице `schedules` (на столько вперёд, сколько отдаёт сайт):

- копия обновляется при каждой удачной загрузке с сайта;
- раз в 2 часа (и через 30 секунд после запуска) бот сам обновляет копии всех таких групп,
  по одной в секунду, чтобы не нагружать сайт. Копии групп, которые больше никто не выбрал, удаляются;
- если сайт не ответил (таймаут 15 секунд), бот показывает копию с пометкой
  «⚠️ Сайт расписания сейчас недоступен. Это сохранённая копия от 8 октября, 14:30».
  Следующие 2 минуты он не ждёт сайт снова, а сразу отдаёт копию.

Расписания преподавателей и групп, которые никто не выбрал своими, не сохраняются:
при недоступном сайте бот так и скажет. Поиск группы и преподавателя тоже требует сайта.

## Файлы

- `vspu.py` — клиент сайта и парсер таблицы
- `formatting.py` — сообщения с расписанием (таблицы, «Сейчас») на языке пользователя
- `search.py` — нечёткий поиск группы и преподавателя, в том числе латиницей
- `i18n.py` и `locales/*.toml` — переводы интерфейса
- `storage.py` — SQLite: выбранные группы и активность пользователей
- `handlers.py` — команды и кнопки (aiogram 3)
- `admin.py` — `/stats`, `/broadcast` и учёт активности
- `schedules.py` — расписание с сайта или из сохранённой копии, фоновое обновление копий, индекс предметов для `/subject`
- `main.py` — запуск
- `tests/` — тесты на сохранённых страницах сайта
- `deploy/install.sh` — установка на Ubuntu как службы systemd

## Запуск

1. Создайте бота у [@BotFather](https://t.me/BotFather) и получите токен.
2. Установите Python 3.11+ и зависимости:
   ```bash
   python -m venv .venv
   .venv/Scripts/activate        # Windows; в Linux: source .venv/bin/activate
   pip install -r requirements.txt
   ```
3. Скопируйте `.env.example` в `.env` и вставьте туда токен (и при желании `ADMIN_IDS`).
4. Запустите:
   ```bash
   python main.py
   ```

Тесты: `python -m pytest`.

## Запуск на сервере (Ubuntu 24.04, systemd)

Скрипт `deploy/install.sh` ставит Python, создаёт системного пользователя `vspubot`,
копирует код в `/opt/vspu-schedule-bot`, собирает venv и регистрирует службу
`vspu-schedule-bot`. Она запускается при загрузке и перезапускается при падении.

| Что | Где |
|---|---|
| код и venv | `/opt/vspu-schedule-bot` |
| токен и настройки | `/etc/vspu-schedule-bot/env` (права 0640) |
| база пользователей | `/var/lib/vspu-schedule-bot/bot.db` |
| unit-файл | `/etc/systemd/system/vspu-schedule-bot.service` |

1. На Windows упакуйте проект (без `.venv` и файлов с токеном) и отправьте на сервер:
   ```powershell
   tar -czf vspu-bot.tar.gz --exclude=.venv --exclude=__pycache__ --exclude=.pytest_cache --exclude=data --exclude=.env --exclude=.env.example -C C:\Users\yurig\projects vspu-schedule-bot
   scp vspu-bot.tar.gz user@server:~
   ```
2. На сервере:
   ```bash
   tar -xzf vspu-bot.tar.gz && cd vspu-schedule-bot
   sudo bash deploy/install.sh
   ```
   Скрипт спросит токен (ввод скрыт), проверит его через Telegram и запустит службу.
   Назначить админов можно сразу или позже, повторным запуском:
   ```bash
   sudo bash deploy/install.sh --admin 123456789
   ```

Обновление: повторите оба шага. Скрипт перезапишет код, но оставит токен и базу.

Управление:
```bash
systemctl status vspu-schedule-bot     # состояние
journalctl -u vspu-schedule-bot -f     # лог
sudo systemctl restart vspu-schedule-bot
```

Один токен нельзя одновременно использовать в двух местах: если бот запущен на сервере,
локальный `python main.py` получит ошибку `TelegramConflictError`.

## Ограничения

- Бот зависит от вёрстки сайта. Если её поменяют, парсер придётся поправить.
  Ячейки незнакомого формата показываются как есть, без разбора на предмет, преподавателя и аудиторию.
- Сайт отдаёт расписание на месяц-два вперёд. На более дальние даты бот ответит, что данных пока нет.
- Время считается по Москве (Воронеж).
